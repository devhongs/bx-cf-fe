# BX-CF 백업 테마 콘텐츠 이식 설계

## 목적

`landing/assets/BX-CF.backup-20260714-162605.pptx`의 테마와 레이아웃을 시각 기준으로 사용하고, 현재 `landing/assets/BX-CF.pptx`의 8개 슬라이드 내용을 대응되는 백업 레이아웃에 이식한다.

커뮤니케이션 목표: 경영진이 채널 파운데이션의 필요성, 구성, 1단계 범위와 기대효과를 기존 브랜드 제안서 형식으로 빠르게 파악하도록 한다.

## 결과물

- 결과 파일: `landing/assets/BX-CF_BackupTheme.pptx`
- 슬라이드 수: 8장
- 원본 두 파일은 수정하지 않는다.
- 백업본의 9페이지 마무리 슬라이드는 제외한다.

## 슬라이드 매핑

| 결과 페이지 | 콘텐츠 원본 | 레이아웃 원본 | 역할 |
|---|---|---|---|
| 1 | 현재 1페이지 | 백업 1페이지 | 표지 |
| 2 | 현재 2페이지 | 백업 3페이지 | 채널 파운데이션 정의 |
| 3 | 현재 3페이지 | 백업 2페이지 | 추진 배경과 필요성 |
| 4 | 현재 4페이지 | 백업 4페이지 | 구성도와 E2E 테스트 자동화 |
| 5 | 현재 5페이지 | 백업 5페이지 | 2명·3개월·1단계 계획 |
| 6 | 현재 6페이지 | 백업 6페이지 | 1단계 산출물 |
| 7 | 현재 7페이지 | 백업 7페이지 | 기대효과와 확장 계획 |
| 8 | 현재 8페이지 | 백업 8페이지 | AI 활용 개발 및 시장 대비 |

백업 9페이지는 결과물에 포함하지 않는다.

## 편집 원칙

- 백업본의 색상, 배경, 폰트, 장식 요소, 카드 및 다이어그램 배치를 유지한다.
- 현재 덱의 제목, 설명, 항목, 기술 스택, 기간·인원·산출물, E2E 자동화 및 AI 관련 문구를 내용 원본으로 사용한다.
- 각 콘텐츠는 의미가 일치하는 상속 텍스트 상자에 직접 입력한다.
- 새로운 시각 체계나 별도 오버레이 레이아웃을 추가하지 않는다.
- 텍스트가 맞지 않으면 의미를 바꾸지 않는 선에서 줄바꿈을 조정한다. 원문을 임의로 요약하거나 새 문구를 추가하지 않는다.
- 페이지 번호와 푸터는 결과 순서 1~8에 맞게 정리한다.

## 검증 기준

- 결과물이 정확히 8장인지 확인한다.
- 현재 덱의 8개 슬라이드 내용이 결과물에 모두 존재하는지 확인한다.
- 4페이지에 `E2E 테스트 자동화` 내용이 유지되는지 확인한다.
- 백업 9페이지의 캐치프레이즈가 결과물에 남지 않는지 확인한다.
- 모든 페이지를 PowerPoint 호환 렌더러로 렌더링해 잘림, 넘침, 비의도적 겹침, 잘못된 줄바꿈을 점검한다.
- 상속된 빈 제목·날짜·푸터·슬라이드 번호 플레이스홀더가 남지 않는지 확인한다.
- 템플릿 충실도 검사를 통과해야 한다.
