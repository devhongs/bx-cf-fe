# BX-CF Soft Block Editorial Revision Design

## Objective

현재 최종본 `landing/assets/BX-CF.pptx`의 Executive Editorial 블루 스타일을 유지하면서, 백지 위에 텍스트가 흩어진 인상을 줄이고 콘텐츠 간 구획과 시각적 우선순위를 강화한다.

최종 파일은 같은 경로와 파일명 `landing/assets/BX-CF.pptx`로 갱신한다.

## Source and Output Contract

- 기준 파일: `landing/assets/BX-CF.pptx`
- 기준 체크섬: `90ffca459339c1815557b0791aab8ac5a6d1bb3b8db255a2f5156843f3badcf8`
- 현재 구성: 9페이지
- 최종 구성: 8페이지
- 9페이지 `오늘 필요한 결정` 삭제
- 1~8페이지의 기존 문구는 그대로 유지
- 4페이지에만 승인된 E2E 테스트 자동화 문구 추가
- 최종 결과는 같은 파일명으로 덮어쓰되, 작업 전 원본은 외부 임시 작업공간에 보존

## Visual System

- 콘셉트: Soft Block Editorial
- 기본 캔버스: 기존의 밝은 아이스 블루·화이트 유지
- 주요 텍스트: 딥 네이비 유지
- 강조색: 코발트 블루 유지
- 보조 면: 옅은 블루 패널을 사용해 콘텐츠 그룹을 묶음
- 구분선: 기존보다 명확한 1px 헤어라인 또는 3~4px 코발트 상단 규칙선 사용
- 그림자와 입체 효과는 사용하지 않음
- 반복 카드 UI처럼 보이지 않도록 큰 면, 번호 레일, 섹션 밴드 중심으로 구성
- 기존 타이포그래피, 상단 섹션 마커, 하단 푸터와 페이지 번호 체계 유지

## Slide-Level Changes

### Slide 1 — Cover

- 현재 구성 유지
- 하단 지표 영역의 구분선과 정렬만 전체 시스템에 맞춰 정돈

### Slide 2 — Definition

- 상단 정의·설명 영역을 옅은 블루 논지 패널로 묶음
- 하단 3개 항목을 동일 폭의 독립 패널로 구성
- 각 패널에 `01`, `02`, `03` 번호와 코발트 상단 규칙선 적용
- 제목, 설명, 결과 문장을 하나의 시각적 단위로 묶어 빈 공간처럼 보이지 않게 구성
- 모든 기존 문구 유지

### Slide 3 — Why Now

- 3개 행을 전체 폭에 가까운 수평 패널로 구성
- 행마다 흰색과 옅은 블루 배경을 교차 적용
- 좌측 번호 영역은 코발트 번호 레일로 분리
- 중앙 원인과 우측 결과 사이의 흐름을 정렬로 명확하게 표현
- 기존 가는 선만으로 구분하던 방식은 제거
- 모든 기존 문구 유지

### Slide 4 — Architecture

- FRONTEND · API 연계 · BACKEND 3개 영역은 동일 폭과 동일 높이로 유지
- 세 영역의 높이를 조정해 하단에 전체 폭의 E2E 테스트 영역 확보
- 하단 E2E 영역은 옅은 블루 밴드와 코발트 상단 규칙선으로 강조
- 다음 문구 추가:
  - `E2E 테스트 자동화`
  - `Playwright · PC · Mobile · Admin 주요 시나리오 검증  →  CI 파이프라인 연동 · Vitest 단위 테스트 병행`
- 기존 아키텍처 문구는 유지

### Slide 5 — Plan

- 3개월 단계를 옅은 블루·화이트의 교차 영역으로 묶음
- 단계 번호, 월, 핵심 제목, 산출물의 수직 정렬을 강화
- 기존 문구 유지

### Slide 6 — Deliverables

- 6개 산출물의 3열×2행 구조는 유지
- 각 항목에 옅은 배경면과 명확한 번호·상단 규칙선 적용
- 빈 공간처럼 보이지 않도록 설명 영역의 배경 대비 강화
- 기존 문구 유지

### Slide 7 — Impact and Roadmap

- 좌측 체크리스트 형식 제거
- 기존 기대효과 6개 항목을 `01`~`06` 번호가 포함된 2열×3행 강조 블록으로 재구성
- 각 블록은 옅은 블루 배경, 코발트 번호, 딥 네이비 본문으로 구성
- 우측 core → mci → full 로드맵과 모니터링 도구 내용은 유지
- 기존 기대효과 문구는 수정하지 않음

### Slide 8 — AI

- 3개 영역에 옅은 배경면을 적용해 PROOF 영역을 중심으로 구획 강화
- 중앙 실증 영역은 다른 두 영역보다 한 단계 진한 블루 톤으로 강조
- 기존 문구 유지

### Slide 9 — Decision

- 페이지 전체 삭제

## Content Rules

- Slide 4의 E2E 문구 추가와 Slide 9 삭제 외에는 문구를 추가·삭제·수정하지 않는다.
- 기존 영문 대소문자, 구분점, 화살표, 숫자 표기를 유지한다.
- 디자인 때문에 줄바꿈 위치는 조정할 수 있으나 문장 내용은 변경하지 않는다.
- 추가 이미지, 로고, 외부 자료, 애니메이션은 사용하지 않는다.

## Verification

- 최종 슬라이드 수 8페이지 확인
- Slide 9가 제거됐는지 확인
- Slide 4 E2E 문구가 정확히 포함됐는지 확인
- Slide 2·3·7의 패널 구획과 텍스트 계층을 전체 크기 렌더로 확인
- Slide 4의 3개 기술 영역이 동일 폭·높이인지 확인
- 모든 슬라이드에서 텍스트 잘림, 예상치 못한 줄바꿈, 겹침, 화면 밖 요소가 없는지 확인
- PowerPoint 압축 패키지 무결성과 렌더링 결과 확인
