# 🖥️ pc-web 로그인 및 메인 대시보드 화면 개발 지시서

`apps/pc-web` (React 19 + TypeScript + Vite) 애플리케이션에 구글 계정 로그인 화면 및 Google AI Studio Playground 레이아웃 구조를 반영하여 로그인/대시보드 페이지를 구현합니다.

---

## 🔑 1. 로그인 화면 구성 (Google 계정 로그인 스타일 레퍼런스)
*   **레이아웃 및 비주얼 (다크 테마)**:
    *   화면 중앙에 가로형의 둥근 모서리를 가진 로그인 카드를 배치합니다. (배경색: 다크 그레이 `#202124`)
    *   **왼쪽 영역**: 서비스 로고(Google 로고 스타일), 대문자 타이틀("로그인"), 서브 가이드 설명 제공.
    *   **오른쪽 영역**:
        *   이메일/아이디 입력란 (보더가 은은하고 포커스 시 테두리가 파란색으로 활성화되는 스타일).
        *   "이메일을 잊으셨나요?" 등의 유틸 링크 배치.
        *   하단 영역에 "계정 만들기" 링크와 "다음" 버튼을 우측 정렬로 배치.
    *   **하단 푸터**: 좌측에 언어 선택기, 우측에 도움말/개인정보처리방침/약관 링크 배치.
*   **기능 동작**:
    *   `@bx/shared`의 `auth` 관련 API를 활용해 아이디/비밀번호 입력을 처리하고 성공 시 토큰 저장 후 `/main`으로 이동시킵니다.

---

## 📊 2. 메인 대시보드 화면 구성 (Google AI Studio Playground 스타일 레퍼런스)
*   **3단 그리드 레이아웃**:
    1.  **좌측 사이드바 (Left Sidebar)**:
        *   상단 로고 영역, 메인 메뉴 그룹(대시보드, 자산 조회 등), 하단 프로필/로그아웃 버튼 영역 구성.
        *   배경색: `#131314` 계열의 극도로 절제된 어두운 톤.
    2.  **중앙 메인 영역 (Center Content)**:
        *   **상단 네비게이션**: 메뉴 토글 버튼 및 현재 페이지명("Playground" 혹은 "대시보드").
        *   **중앙 타이틀**: "Explore Google models" 스타일의 메인 표제.
        *   **콘텐츠 그리드**: 2x3 카드 배열로 구성 (Featured, 자산, 송금, 알림 등 비즈니스 정보 요약을 세련된 카드로 표현).
        *   각 카드 내부에 아이콘, 제목, 짧은 요약 텍스트 배치.
        *   하단 영역에 프롬프트 스타일의 퀵 검색/송금 입력 바 배치.
    3.  **우측 설정 패널 (Right Sidebar)**:
        *   자산 상세 설정이나 빠른 이체 옵션을 세부 조율할 수 있는 사이드 설정 바 배치 (온도 슬라이더, 드롭다운 셀렉트 등의 세련된 UI 폼 요소 구성).

## 🎨 3. 공통 디자인 표준 및 기술 스택
*   **기술 스택**: React 19 + TypeScript + Vite + CSS Modules (`*.module.css`) 사용.
*   **디자인 Aesthetics**:
    *   전체적으로 `#131314` 배경의 다크 테마를 적용하며, 카드는 `#1e1f20` 계열로 깊이감을 표현.
    *   보더 둥글기(border-radius)는 8px~12px 수준으로 둥글고 세련되게 처리.
    *   포커스, 호버 시 구글 스타일의 블루 컬러 포인트 테두리 활성화 및 미세한 스케일 애니메이션 추가.
*   **공통 모듈 재사용**:
    *   `@bx/shared` 내 공통 컴포넌트(`Button`, `Input`, `Select`) 및 `entities` 내 `account` 훅(`useFetchAccountList`, `useSetFavoriteAccount`)을 임포트하여 화면 레이아웃 구성.
